AI Fingerprinting Model Hierarchy Schema
Version 1.2

Inference hierarchy:
family -> architecture -> variant

Examples:
cnn -> resnet -> resnet50
rnn -> lstm -> bilstm_2layer
transformer -> bert -> bert_base
autoencoder -> variational_autoencoder -> beta_vae
gnn -> gat -> gat_8head
diffusion -> latent_diffusion -> stable_diffusion_v1_5
gan -> stylegan -> stylegan2_ada
mlp -> feedforward_mlp -> mlp_4layer
state_space -> mamba -> mamba_small

Important:
precision, batch size, input size, framework, runtime, device, and application
are separate experimental attributes. They are not model variants.

Runtime behavior:
native runtime lists only variants with a native implementation for the
selected framework. Artifact runtimes such as ONNX Runtime, TensorRT, and
TFLite expose the broader taxonomy and require a model artifact.

v0.8.7 native-training coverage highlights:
cnn -> resnet/mobilenet/efficientnet -> multiple variants
rnn -> lstm/gru -> multiple variants
transformer -> tiny_transformer -> 2/4/6-layer
transformer -> bert -> tiny/mini/small/base/large (PyTorch + transformers)
transformer -> distilbert -> base (PyTorch + transformers)
transformer -> vit -> B/16, B/32, L/16 (PyTorch torchvision)
autoencoder -> dense_autoencoder -> 2/3/5-layer
autoencoder -> convolutional_autoencoder -> 2/4/6-layer
autoencoder -> variational_autoencoder -> FC/Conv/Beta-VAE; reconstruction + anomaly_detection
mlp -> feedforward_mlp -> 2/4/8-layer

Catalog-only entries remain explicitly marked artifact-only where the generic
training loop does not implement the task correctly (for example GAN,
diffusion, object detection, and current GNN/state-space entries).

AI Fingerprinting Model Hierarchy Schema
Version 1.2

Inference hierarchy:
family -> architecture -> variant -> application

Examples:
cnn -> resnet -> resnet50 -> image_classification
rnn -> lstm -> bilstm_2layer -> activity_recognition / text_classification
transformer -> bert -> bert_base -> text_classification / masked_language_modeling
autoencoder -> variational_autoencoder -> beta_vae -> reconstruction / anomaly_detection
gnn -> gat -> gat_8head
diffusion -> latent_diffusion -> stable_diffusion_v1_5
gan -> stylegan -> stylegan2_ada
mlp -> feedforward_mlp -> mlp_4layer
state_space -> mamba -> mamba_small

Important:
precision, batch size, input size, framework, runtime, device, and dataset
are separate experimental attributes. Application is now a fingerprint target,
but it remains separate from the model variant.

Runtime behavior:
native runtime lists only variants with a native implementation for the
selected framework. Artifact runtimes such as ONNX Runtime, TensorRT, and
TFLite expose the broader taxonomy and require a model artifact.

Catalog-only entries remain explicitly marked artifact-only where the generic
training loop does not implement the task correctly (for example GAN,
diffusion, object detection, and current GNN/state-space entries).
